# Strategy & Consulting Group Website

A static consulting company website designed for GitHub Pages.

## Edit the site

- Update company name, copy, and email in `index.html`.
- Update colors and layout in `styles.css`.
- Replace the contact form action with your own Formspree, Basin, or other static-form endpoint.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Add these files to the repository root.
3. In GitHub, open **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder.
6. Save, then wait for GitHub to publish the site.

The custom domain for this website is:

```text
strategyandconsultinggroup.com
```

Your temporary GitHub Pages URL will also be available at:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
```

If this is your user or organization site repository named `YOUR-USERNAME.github.io`, the site will publish at:

```text
https://YOUR-USERNAME.github.io/
```
